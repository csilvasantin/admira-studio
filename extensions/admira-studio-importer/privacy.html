Privacidad de AdmiraStudioImporter

Actualizada para la versión 1.0.4

La extensión AdmiraStudioImporter permite buscar o elegir un vídeo de YouTube y preparar su importación al Stock de Admira Studio.

El buscador integrado y la comprobación de sesión para elegir proyecto se incorporan en la versión 1.0.4. En las versiones anteriores, la extensión prepara la importación a partir de un vídeo abierto en YouTube y la comprobación del acceso se realiza en Admira Studio.

Cuándo se transmiten datos

Al pulsar Reproducir vídeo, el panel carga el reproductor integrado de YouTube. YouTube recibe el identificador del vídeo y de la extensión para servir la reproducción y aplica su propia política de privacidad.

Al usar el buscador, la extensión envía la consulta a YouTube. Para mostrar el selector de proyectos, consulta la sesión existente en admira.studio y carga el catálogo público de proyectos de Yokup. El inicio de sesión se realiza en Admira Studio con Google. Al pulsar Importar en Admira Studio, la extensión abre el Stock mediante HTTPS con la URL y el título del vídeo, el comentario, las etiquetas y las opciones de importación, incluido el destino elegido cuando se indica un proyecto. Admira Studio utiliza esos datos para ejecutar la importación solicitada.

Subtítulos opcionales para cápsulas

Si eliges subtítulos en castellano o inglés, Admira Studio extrae el audio del vídeo importado y lo envía a Cloudflare Workers AI para transcribirlo y traducirlo. El vídeo con subtítulos visibles se genera en tu navegador y se guarda como una nueva versión en Stock, conservando el original. Si eliges formato vertical, horizontal o ambos, el navegador prepara las copias con la imagen completa y el audio original; este ajuste de formato no envía el vídeo a un servicio de IA. Ambas opciones se aplican solo al vídeo seleccionado y no se guardan como preferencias. La extensión no envía directamente audio a servicios de IA ni contiene claves. Mantén Stock abierto durante el proceso y revisa los subtítulos automáticos.

Lo que no hacemos

  • No vendemos datos ni los usamos para publicidad, perfiles comerciales o decisiones crediticias.
  • La extensión consulta el estado de sesión mediante una solicitud autenticada a Admira Studio. No lee el valor de la cookie, las contraseñas, el contenido del correo, los contactos ni el historial completo del navegador.
  • No incorporamos analítica, anuncios, rastreadores ni código remoto.
  • No compartimos información con terceros ajenos a la prestación solicitada.

Permisos de Chrome

El permiso de reglas de red permite identificar a la extensión únicamente en las solicitudes de su reproductor integrado a YouTube.

El permiso de YouTube permite buscar vídeos y detectar los metadatos del vídeo abierto. El permiso de admira.studio permite consultar la sesión y recuperar el catálogo de respaldo. La extensión usa el panel lateral para mostrar el importador, almacenamiento para conservar preferencias y contexto temporal, y el menú contextual para ofrecer la acción de importación.

Seguridad, eliminación y derechos

La transferencia hacia Admira Studio se realiza exclusivamente mediante HTTPS. Para borrar las preferencias locales, elimina los datos de la extensión o desinstálala. Para solicitar acceso, rectificación o eliminación de contenidos ya importados en Admira Studio, escribe a hola@admiranext.com.

El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de Chrome Web Store, incluidos sus requisitos de Uso Limitado. / The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

English summary

AdmiraStudioImporter sends submitted searches to YouTube, reads public video metadata and checks the existing Admira Studio session to list available projects. The selected video and import options are sent to Admira Studio when the user requests an import. Chrome stores import preferences. The extension contains no analytics, ads or remotely loaded code. Contact: hola@admiranext.com.
