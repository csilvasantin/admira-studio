Privacidad de AdmiraStudioImporter

Última actualización: 26 de octubre de 2026

Esta política describe el tratamiento de datos realizado por la extensión AdmiraStudioImporter. Su única finalidad es preparar, a petición del usuario, la importación del vídeo de YouTube abierto hacia el Stock de Admira Studio.

Responsable y contacto

Carlos Silva (Admira Studio). Para privacidad, soporte o eliminación de datos: hola@admiranext.com.

Cuándo se transmiten datos

La extensión no envía información en segundo plano. Solo cuando el usuario pulsa Importar en Admira Studio, abre mediante HTTPS una página de www.admira.studio con la URL del vídeo, su título y los campos opcionales introducidos. Admira Studio procesa esos datos para ejecutar la importación y guardar el contenido solicitado en el Stock. El acceso final puede requerir una cuenta autorizada de Admira Studio.

Subtítulos opcionales para cápsulas

Si marcas «Cápsula con subtítulos en castellano», Admira Studio extrae el audio del vídeo importado y lo envía a Cloudflare Workers AI para transcribirlo y traducirlo. El vídeo con subtítulos visibles se genera en tu navegador y se guarda como una nueva versión en Stock, conservando el original. Esta opción solo se aplica al vídeo seleccionado; no se guarda como preferencia. La extensión no envía directamente audio a servicios de IA ni contiene claves. Mantén Stock abierto durante el proceso.

Lo que no hacemos

  • No vendemos datos ni los usamos para publicidad, perfiles comerciales o decisiones crediticias.
  • No accedemos a contraseñas, cookies, correos, contactos ni al historial completo del navegador.
  • No incorporamos analítica, anuncios, rastreadores ni código remoto.
  • No compartimos información con terceros ajenos a la prestación solicitada.

Permisos de Chrome

La extensión limita su acceso a páginas de YouTube. Usa el panel lateral para mostrar el importador, almacenamiento para conservar preferencias y contexto temporal, y el menú contextual para ofrecer la acción de importación. No solicita acceso al contenido de admira.studio.

Seguridad, eliminación y derechos

La transferencia hacia Admira Studio se realiza exclusivamente mediante HTTPS. Para borrar las preferencias locales, elimina los datos de la extensión o desinstálala. Para solicitar acceso, rectificación o eliminación de contenidos ya importados en Admira Studio, escribe a hola@admiranext.com.

El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de Chrome Web Store, incluidos sus requisitos de Uso Limitado. / The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

English summary

AdmiraStudioImporter only reads the current YouTube video's URL and visible metadata to prepare an import explicitly requested by the user. Preferences are stored in Chrome; no analytics, ads, remote code or background transmission are used. Data is sent over HTTPS to Admira Studio only after the user presses the import button. Contact: hola@admiranext.com.
