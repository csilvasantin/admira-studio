La capa Crear de la red

admira.studio es la fábrica de contenido del ecosistema AdmiraNeXT (gemelo de pixeria.com): de una idea a piezas listas para emitir — imagen, vídeo, audio, avatar — y a campañas distribuibles por circuitos. Para agentes (silicio) y personas (carbono).

capa Crear · hub MCP & federación

Tres verbos, una red

Crearadmira.studio — generar contenido con IA y montar campañas (esta pata).
Operarxpaceos.com — el OS de la flota: pantallas, robots, emisión y audiencia.
Emitiradmira.tv — el canal que reproduce en las pantallas.

Superficies de creación

ideaidea.html — de brief a concepto creativo.
imágenesimagenes.html — generación de imágenes para pantalla.
audioaudio.html — locución y pistas de audio.
avataravatar.html — avatares que hablan (facecap + visemas).
campañacrear-campana/ — monta una campaña y la asigna a circuitos.

Operar la red (servidor MCP real)

La capa Crear no expone aún servidor MCP propio (se crea por la web). Para operar la red — flota, emisión, audiencia — el ecosistema expone un servidor MCP real bajo mcp.admira.store:

Config de cliente:

{
  "mcpServers": {
    "xpaceos": {
      "url": "https://mcp.admira.store/mcp"
    }
  }
}

Prueba rápida (tools/list):

curl -s https://mcp.admira.store/mcp \
 -H "Content-Type: application/json" \
 -d '{"jsonrpc":"2.0","id":1,
      "method":"tools/list"}'
