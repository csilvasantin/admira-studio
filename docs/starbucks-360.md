# Starbucks 360

In Expert mode on Studio, Biz, TV, App or Store, run `/contenido starbucks 360`. The single suite engine opens `/campanas/starbucks-360/` on Studio; the normal Studio login remains in place. The `start=1` entry resumes and synchronises the seven already installed native players. Normal visits play the 3D preview without controlling hardware; the explicit start button can repeat activation.

The activation endpoint requires the existing owner session, same-origin JSON and the fixed `start` action. It accepts no screen IDs, URLs, shell commands or playlist changes. It sends resume followed by sync only to the seven configured players. Queued requests are distinct from actual playback: the viewer reads current item IDs, URLs, sync and heartbeat freshness before showing physical progress. Closed native applications must first be opened through their existing OS/Fleet access.

Stock revision 6 contains 18 native Creador/Adaptador videos. The shared cycle is ES mural 24 s, ES individual 8 s, EN mural 24 s, EN individual 8 s. Lower copy changes with each arrival. The separately confirmed physical MacMini V1/V3 bindings are retained. The model is a nominal synchronization layout; its physical dimensions are not surveyed.

The player and preview retain the outgoing frame until a clock-aligned frame is decoded, then crossfade over 320 ms. The native helper warms the following item, validates decoded mediaTime and cancels obsolete clock turns. Escape has an existing coordinated stop hook; use H to hide 3D/Matrix panels without closing native players.
