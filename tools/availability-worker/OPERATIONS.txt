The scheduler calls one Durable Object. The persisted five-minute slot prevents
repeated platform deliveries from creating duplicate measurements. Public GETs
only read state; public POSTs and private /tick access are rejected.

Globalping: 18 tests per cycle, 216/hour. ES residential (Telefonica preferred),
Germany and USA. Six checks per network: version, apex entry redirect, protected
login, www entry redirect, apex DNS and www DNS. Validate TLS, hostname, expiry,
public A answers and expected page semantics. This is sampled network coverage,
not a guarantee for every ISP/country or for content generation/import services.

Cloud anonymous egress can share Globalping's per-IP quota. A dedicated
GLOBALPING_TOKEN Worker secret is supported. Never put it in this repository,
reports, logs or a browser URL. Authenticated free allowance is currently 500
measurements/hour; do not buy credits or enable billing without Carlos's request.
If quota/API/probe coverage fails, status is UNKNOWN, never website DOWN.

A target check must fail in the same country in two consecutive cycles to open
an incident. A lone failure is SUSPECT. Preserve last known state across unknown
coverage, report recovery, warn TLS expiry within 14 days. A 20-minute-old report
is stale. The reader deduplicates notices and retrieves retained incidents missed
while the desktop was unavailable.

Cloud observations continue with both Macs off. Chat delivery still needs a Codex
heartbeat on the desktop. No instant alerts or detection-before-every-visitor
promise. The active heartbeat is vigilar-admira-studio in Carlos's existing chat.

Reader: python3 scripts/read-availability.py --state PATH
It reads the compact report directly. If workers.dev is unreachable on the
residential route, it reads the SAME report through an external HTTPS probe.
It does not change DNS/hosts or run the website's measurements from the Mac.
The relay keeps HTTP path and query separate and rejects truncated/untrusted data.
